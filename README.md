# WarCounter

Compagnon francophone pour Warhammer Age of Sigmar (4e édition).

Application web gratuite, installable sur téléphone et ordinateur, utilisable hors ligne : https://elcounter.github.io/warcounter/

## Fonctionnalités

- **Listes** : création de listes d'armée pour les 25 factions, avec vérification des règles de construction, partage en texte et export/import.
- **Mémo** : toutes les aptitudes de ta liste ou d'une faction, avec une recherche.
- **Phases** : les aptitudes utilisables à chaque phase du tour.
- **Règles** : règles de base et avancées, Manuel du Général et règles des factions, avec une recherche globale.
- **Parties** : feuille de bataille pour suivre les scores, les battleplans et les Battle Tactics.
